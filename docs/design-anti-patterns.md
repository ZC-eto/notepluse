## B. 设计总则（反模式 → 正确做法）

### B1. 禁止「大标题 + 一大段说明」
- **反**：`h3 粗体` + `p.confirm-msg` 两行说教  
- **正**：短标题即可；说明最多一行 muted，能 tooltip 就 tooltip  
- **扫**：`PromptDialog` / `ConfirmDialog` / `askPrompt({ message })` / `settings-foot` / `onboard-desc`

### B2. 禁止滥用「方框 + 文字」
- **反**：每个动作都是 `btn-ghost` / `btn-solid` / `seg-btn` 描边胶囊  
- **正**：图标按钮；文字仅在主 CTA 或菜单里；分段用下划线/轻底，不用厚 pill  
- **扫**：`.seg-btn`、`.btn-solid` 成排出现、`.status-chip` 装饰性使用、日历工具栏

### B3. 禁止无理由粗体（≥650）
- **反**：folder-label / confirm-title / settings-card-title 全 700–800  
- **正**：正文 400–500；强调 550–600；几乎不用 700+  
- **扫**：`font-weight: 650|700|750|800`

### B4. 禁止「帮助墙」
- **反**：每个控件旁 HelpTip + 横幅 banner + 空状态三段文案  
- **正**：一处入口（快捷键表 / 设置 FAQ）；界面自解释  
- **扫**：`HelpTip` 密度、`cal-banner`、`view-alert`

### B5. 禁止平铺无层级
- **反**：详情 6 格同权卡片；设置每项同等边框  
- **正**：主信息大、次信息折叠/淡出  

### B6. 禁止 chrome 抢内容
- **反**：工具条双行、compose 条厚、margin 卡片壳  
- **正**：单行 32–36px chrome；主区贴边

## C. 全库扫视命中（2026-07-21）

### C1. 粗体过重（CSS / scoped）
- `src/styles/main.css`：大量 650–800（brand、folder、toolbar、settings、onboard）  
- `TaskInspector.vue` scoped：title 650、chips 600  
- **动作**：统一降到 500–550；仅 active/selected 可用 600

### C2. 方框文字控件堆叠
| 位置 | 问题 |
|------|------|
| `CalendarView` 工具栏 | 上月/下月/今天/本篇/全部 = 典型「方框文字墙」 |
| `ScopeSeg.vue` | 全局分段都是 pill |
| `SettingsPanel` | 默认视图 4 个 seg-btn + 排版/源码 + 紧凑/舒适 |
| `GanttView` / `TodoView` 工具栏 | 状态 chip + 本篇/全部 |
| `TopBar` 旧 save 实心钮 | 已部分图标化 |

### C3. 冗长 message 文案
| 调用 | 问题 |
|------|------|
| `createFolder` askPrompt | 两行「待办类请放…笔记请放…」说教 |
| `renameFolder` | 「将「x」重命名为：」可缩短 |
| 多处 Confirm | 可保留一句，但不要再加第二段 |
| Calendar help 常量 | 超长图例句，应进图例菜单而非顶栏 |

### C4. 日历交互缺口
- 无 ↑↓ / ←→ 翻月  
- 无单日视图（点格子只 + 或无反应）  
- 任务单击=选中详情，无双击语义；空白单击无「进入当日」  
- 空状态整条 banner + 「为今天新建」= 又一方框带字  

### C5. Dialog 结构
- `PromptDialog`：`confirm-title` 粗 + `confirm-msg` 说明 + 双按钮描边  
- 应改为：标题一行（medium）· 无 message 或一行 faint · 主按钮轻量

## D. 日历目标交互（本轮规格）

```text
Month view
  ← / → 或 ↑ / ↓     上/下月
  T                  今天
  单击日期空白       进入 Day view（当日议程，可链到甘特）
  单击任务条         选中（轻高亮）
  双击任务条         打开详情 sheet
  单击 +             快速添加（轻量，非大方框工具条）

Day view
  Esc / 返回         回月视图
  列表展示当日事件（时间/时长/标题）
  可「在甘特中查看」跳转
```

工具栏：图标 chevron · 月份文字 · 今天用文字链或轻按钮，**去掉并排粗框**。

---

## E. Prompt / Confirm 目标

```text
新建文件夹
  标题：新建文件夹
  （无大段说明）
  [输入框]
  取消 · 创建
```

`message` 仅在真正危险操作保留一句。
