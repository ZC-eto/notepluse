# 编辑器壳层打磨 v0.7.1

日期：2026-07-20

## 目标

打开笔记后立刻进入「写正文」状态：去掉双导航、产品说明书文案、0 状态诊断条，工具栏图标化，模式命名准确。

## 已改

| 区域 | 变化 |
|------|------|
| TopBar | 删除「笔记原文 / 书写与阅读 Markdown」与顶栏第二套视图 Tab；标题仅显示文件名；模式改为「排版 / 源码」；说明进 `?` 悬浮层 |
| Editor 工具栏 | 图标按钮 + 分组分隔；「任务块」→「任务组」；快捷键写进 tooltip |
| Task 状态条 | 仅诊断 > 0 时显示；0 时整段不渲染 |
| 左 rail | 保留唯一导航；去掉 WORKLINE 装饰字 |
| 底栏 | 去掉「Markdown 是唯一真源」；状态改为 已保存/未保存/保存中 |
| 侧栏/空态 | 「N 篇」；更短 onboarding；新建默认仍为 `笔记-日期` / 示例 `快速开始` |
| demo | 不再自动打开示例笔记 |
| 文案 | 用户可见处优先「任务组」而非 Task Block 黑话 |

## 关于「本周计划」

代码路径已不再创建「本周计划」。若界面仍显示该标题，是**本地已有文件名**，请在侧栏重命名或删除。新建会用 `笔记-YYYY-MM-DD`。
